# Number Quest - Python Game 🎮

A fun number guessing game built using Python and Tkinter.

## Features
- Player name and welcome screen
- Easy, Medium, and Hard difficulty levels
- Limited guessing attempts
- Score system
- Win and lose sound effects
- Play Again and Change Player options

## Technologies Used
- Python
- Tkinter
- Random module
- Winsound (Windows)

## How to Run
1. Install Python on Windows.
2. Download `Number_Quest_Game.py`.
3. Open it using Python IDLE.
4. Press F5 to run the game.

Created as a Python learning project.
